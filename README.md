# Spass - Chrome Extension

**Spass** is a simple and secure password manager Chrome extension for storing and retrieving passwords across different websites.

## Features

- 🔐 Save passwords for different websites
- 🧠 Automatic credential detection on login pages
- 💡 Credential suggestions appear in a popup near login forms
- 🔍 Search through saved passwords
- 👁️ View, copy, and delete stored credentials
- 🔒 Secure storage using Chrome's sync storage


## Installation

1. Download or clone this repository.
2. Open Chrome and navigate to `chrome://extensions/`
3. Enable **Developer mode** (top right corner).
4. Click on **Load unpacked** and select the `spass` directory.
5. Start using Spass to securely manage your passwords.
